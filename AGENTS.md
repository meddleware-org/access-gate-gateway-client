# AGENTS.md — @meddleware/access-gate-gateway-client

| Field | Value |
| --- | --- |

## Layout

```text
src/
  index.ts      public re-exports
  types.ts      Challenge, AccessProof
  challenge.ts  fetchChallenge
  proof.ts      personalMessage, buildAccessProof, encode/decodeAccessProof, gatewayOrigin, isNonce, isTransactionDigest
  contract.ts   gateway response contract (statuses, conflict codes, parseGatewayError)
vectors.json   conformance vectors (generated by scripts/gen-vectors.mjs; published)
tests/          vitest unit tests, incl. vectors.json verified with an independent verifier (@mysten/sui)
```

## Rules

- The wire format (`nft-gate:access:v2` message, base64(JSON) proof, field order) is shared with both
  gateways in `meddleware-org/access-gate-gateway` and pinned by `vectors.json` — change them together.
- `access_gate` builders/reads belong in `@meddleware/access-gate-client`, not here.
- No runtime dependencies; no hardcoded addresses; no secrets.
